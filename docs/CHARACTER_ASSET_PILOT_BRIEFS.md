# Module 2 Pilot Character Briefs

## Status and purpose

These briefs define the first review batch for the Module 2 character asset system. They are production briefs only. They do not authorize asset generation, application-code changes, scoring changes, deployment, or release.

The pilot uses one Enneagram archetype across all three approved presentation values. This isolates presentation parity from personality variation and tests whether the asset template can preserve the same visual meaning without mapping body shape to gender.

## Shared pilot recipe

| Attribute | Locked direction |
|---|---|
| Enneagram core | 5 |
| Archetype | นักทำแผนที่เชิงระบบ — System Mapmaker |
| Core meaning | Connect complex information into a map that people can understand and use |
| Primary prop | System map with modular data tiles |
| Pose direction | Left |
| Background motif | Data nodes and connected routes |
| Core palette | Forest `#16362F`, ivory `#FEFDFA`, matcha `#3E6D58`, sage `#8BA79B`, charcoal `#333333` |
| Presentation variants | `female`, `male`, `neutral` |
| Pilot Wing state | Ambiguous; no Wing-specific prop or accent |
| Pilot MBTI state | Neutral energy; no MBTI-specific posture or motif overlay |
| Pilot identity state | Neutral lighting study; no A/T treatment |
| Output stage | Brief and review criteria only |

### Locked anatomy and composition

- Use one balanced adult proportion guide for all three variants.
- Keep identical height, body shape, build, shoulder width, limb proportions, head-to-body ratio, hand size, and apparent age.
- Body shape, weight, muscularity, height, and physical build must not encode personality or gender.
- Keep the same camera, focal length, canvas position, silhouette scale, pose intent, gaze direction, prop size, and lighting hierarchy.
- The character stands in a stable but relaxed three-quarter pose, turned slightly left toward the system map.
- One hand supports the map; the other arranges a data tile. The pose communicates observation and synthesis, not withdrawal, superiority, or emotional coldness.
- Expression is attentive and quietly curious, with relaxed brows and a slight welcoming softness around the eyes.
- Keep the face and primary prop inside the central 76% safe region with at least 8% transparent space on every edge.

### Locked styling

- Warm, approachable, softly modeled 3D illustration consistent with the existing guild image.
- Practical layered clothing with clean geometric seams; no occupational uniform, prestige cue, lab coat, academic regalia, or executive styling.
- Equal material quality, lighting, detail density, contrast, and polish across variants.
- The core prop and system-map motif must identify the archetype without relying on color.
- No baked-in text, number, personality code, Enneagram symbol, MBTI letters, logo, or participant data.
- No Wing signal. No gender-coded color palette. No presentation variant may appear more capable, authoritative, warm, attractive, or complete.

## Brief 01 — System Mapmaker / Female Presentation

### Asset identity

- Proposed runtime ID: `enneagram-5-female`
- Proposed runtime path: `/character-assets/enneagram-5/female.webp`
- Presentation value: `female`
- Personality recipe: identical to Briefs 02 and 03

### Visual direction

Create an adult System Mapmaker using the shared anatomy, pose, clothing construction, props, and composition. Female presentation may be communicated through restrained, non-anatomical styling cues such as hair treatment or garment detailing. Those cues must not alter body shape, facial maturity, pose confidence, clothing practicality, or the prominence of the system map.

Hair must not obscure the eyes, face, hands, or data tiles. Avoid exaggerated eyelashes, cosmetic emphasis, narrowed waist, enlarged chest or hips, smaller stature, delicate hands, submissive pose, or softer lighting relative to the other variants.

## Pilot comparison sheet specification

Review the three pilots together on one contact sheet before any remaining characters are commissioned.

The sheet must show:

1. all three transparent assets at identical scale on the same neutral background;
2. silhouette overlays at 50% opacity to expose proportion drift;
3. grayscale thumbnails to test hierarchy without palette cues;
4. crops at planned desktop size and at the 360 px mobile result size;
5. face, hands, and primary-prop detail crops;
6. file ID, dimensions, byte size, and review status outside the artwork.

Reviewers must compare presentation parity before assessing whether the System Mapmaker archetype is recognizable.

## Pilot acceptance criteria

The pilot batch is **PASS** only when:

- all three variants use the same approved balanced adult proportions and silhouette scale;
- no body-shape, build, height, weight, muscularity, pose authority, or production-quality difference encodes presentation;
- the System Mapmaker meaning is recognizable from pose and prop without labels or color;
- female, male, and neutral variants are equal in warmth, competence, maturity, detail, and prominence;
- no Wing, MBTI, or A/T treatment is accidentally implied;
- all critical details remain readable at 360 px without clipping or horizontal overflow;
- accessibility descriptions accurately communicate the meaningful action and prop;
- exported test files, when later authorized, meet the Module 2 safe-area, transparency, sRGB, and file-budget rules;
- Design, Product, Accessibility, and HR/Privacy approve the comparison sheet.

Any proportion drift, body-shape mapping, gender stereotype, unequal finish, unreadable core prop, or ambiguous role makes the pilot **FAIL / NO-GO**. Correct the shared template before producing the remaining 24 base characters.

## Decisions required before asset generation

- Approve Enneagram 5 as the proof archetype.
- Approve the shared balanced-adult proportion guide.
- Approve the allowed presentation cues and prohibited stereotypes.
- Approve the softly modeled 3D direction against the existing guild image.
- Assign asset creator, reviewers, source-tool policy, provenance format, and ownership approver.
- Confirm that the pilot remains Wing-, MBTI-, and A/T-neutral until base parity passes.
